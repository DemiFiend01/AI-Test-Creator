# AI-Test-Creator
Aplikacja, która na podstawie przesłanego pliku PDF lub tekstu generuje test zawierający różne typy adekwatnych pytań. Użytkownik może następnie rozwiązać test, a AI ocenia jego odpowiedzi i podaje informację zwrotną.
